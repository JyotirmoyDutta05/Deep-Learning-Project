# Study Guide: RNN vs LSTM vs GRU, When Does Gating Actually Help?

Everyone in the group should read this fully and be able to explain every section. Read it together with `PROJECT_README.md` (full technical write-up with tables), `rnn_lstm_gru_project.py` (the code) and the `results/` folder (figures and CSVs).

## 0. The 30-second version (memorise this)

> Textbooks say vanilla RNNs forget over long sequences because of vanishing gradients, and that LSTM and GRU fix this with gates. We tested that claim experimentally. We built one model class that can switch between RNN, LSTM and GRU. We trained them on a synthetic memory task where the difficulty is controlled exactly by the sequence length, measured the gradients directly, and then trained them on real IMDB movie reviews and looked inside the networks. Our main finding is that **gates help only if they start in the "remember" state**. With default initialisation the LSTM and GRU fail just as badly as the plain RNN, while with the gate bias set to 2 the GRU remembers over 100 steps. On IMDB, the GRU was best (about 82%), then the LSTM (about 76%), then the RNN (about 64%).

| Experiment 2a (untrained gradients) | **Random Gaussian noise** | Generated in the code (`torch.randn`) |

The terminal output showed the download (`train-00000-of-00001.parquet`, etc.) and then `Dataset: IMDB | train=10000 test=4000 vocab=10000` |

Important details to know:
- IMDB has 25,000 training and 25,000 test reviews. **We used a random subset of 10,000 for training and 4,000 for testing** (fixed seed) so that it runs quickly on a laptop.
- It is a **binary classification** task: read a review, predict positive (1) or negative (0). Chance accuracy is 50%.
- The script has two backup datasets (a 2,000-review movie corpus, and a tiny synthetic sentiment set) that only activate if the IMDB download fails. **They were not used in our final results.**
- Why two kinds of data? The synthetic task isolates one thing (long-range memory) under full control. IMDB checks whether the ideas also matter on real language.

### The synthetic memory task in plain words
Each sequence has length `T`. At step 0 we show one of 8 symbols (one-hot vector on a "signal" channel). At every later step we show a random distractor symbol on a *different* channel. At the end the network must say which symbol it saw at step 0. A network that guesses gets 1/8 = 12.5%. The only way to score high is to **carry information across all T steps while ignoring distractors**. We make it harder simply by increasing T (10, 25, 50, 100).

## 2. Background you must understand

### 2.1 What a recurrent network does
It reads a sequence one element at a time and keeps a **hidden state** `h_t`, a vector that is its running memory:
```
h_t = tanh(W_xh x_t + W_hh h_{t-1} + b)        (vanilla RNN)
```
The final hidden state goes through a linear layer to make a prediction.

### 2.2 Vanishing gradients (the core idea)
Training uses **backpropagation through time**. The loss is computed at the last step `T`, and the gradient has to travel back to earlier steps:
```
∂L/∂h_t = ∂L/∂h_T · ∏_{k=t+1..T} ∂h_k/∂h_{k-1}
```
For the vanilla RNN each factor is `diag(1 - h_k²) · W_hh`. Multiplying many factors smaller than 1 gives an exponentially small number:
```
‖∂h_T/∂h_t‖ ≤ (γ · σ_max(W_hh))^(T-t)
```
(γ ≤ 1 is the biggest tanh derivative, σ_max the largest singular value of `W_hh`.)
**Meaning:** the weights that process step 1 receive almost no learning signal, so the network cannot learn that step 1 matters for the answer.
- If the factor is greater than 1 instead, gradients **explode**. We prevent that with **gradient clipping** (if the gradient norm exceeds 1, rescale it to norm 1).
- Also, a tanh unit stuck near ±1 ("saturated") has derivative `1 - h² ≈ 0`, which makes things worse. That is what our saturation histogram measures.

### 2.3 LSTM
```
f_t = σ(W_f [x_t, h_{t-1}] + b_f)      forget gate  (how much old memory to keep)
i_t = σ(W_i [x_t, h_{t-1}] + b_i)      input gate   (how much new info to write)
g_t = tanh(W_g [x_t, h_{t-1}] + b_g)   candidate memory
o_t = σ(W_o [x_t, h_{t-1}] + b_o)      output gate  (how much memory to reveal)
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t        cell state (the long-term memory)
h_t = o_t ⊙ tanh(c_t)
```
(σ = sigmoid, outputs between 0 and 1; ⊙ = element-wise multiplication.)
The key line is `c_t = f_t ⊙ c_{t-1} + ...`. The path from `c_{t-1}` to `c_t` has derivative `diag(f_t)`, with **no weight matrix and no tanh** on it. If `f_t ≈ 1`, the gradient flows back almost unchanged.

### 2.4 GRU (simpler: 2 gates, no separate cell state)
PyTorch's convention (we use PyTorch, so use this one):
```
r_t = σ(W_r [x_t, h_{t-1}] + b_r)                reset gate
z_t = σ(W_z [x_t, h_{t-1}] + b_z)                update gate
n_t = tanh(W_n x_t + r_t ⊙ (W_hn h_{t-1}) + b_n)
h_t = (1 - z_t) ⊙ n_t + z_t ⊙ h_{t-1}
```
In PyTorch `z` multiplies the **old** state, so a large `z` means "keep the old memory". (Some textbooks write it the other way round; do not be confused if asked.)

### 2.5 The catch that our project is built around
The "gates fix vanishing gradients" story is **conditional**. It only works if the forget/update gate is actually close to 1. A gate with bias 0 starts at `σ(0) = 0.5`, so the memory is halved at every step, `0.5^25 ≈ 3×10⁻⁸`. So at the start of training the LSTM is just as forgetful as an RNN. Whether it escapes depends on whether training finds a way to open the gates. **Initialising the bias to a positive value** (we use 2, so `σ(2) ≈ 0.88`) starts the gates mostly open. This is a standard trick in the literature (Jozefowicz et al., 2015), not something we invented.

### 2.5b Parameter counts
For input size D and hidden size H: RNN = `H(D+H) + 2H`; LSTM = 4× that; GRU = 3× that. (The LSTM has 4 weight blocks: i, f, g, o. The GRU has 3: r, z, n.) On our memory task: RNN 5,768, LSTM 21,512, GRU 16,264 parameters.

## 4. The experiments: what we did, what the figure shows, what to say

### Experiment 1: long-range memory (`exp1_memory_accuracy.png`, `exp1_loss_curves.png`)
**What we did:** Trained all 5 variants for T = 10, 25, 50, 100 and measured how often the network recalls the first symbol.

| Model | T=10 | T=25 | T=50 | T=100 |
|---|---|---|---|---|
| RNN | 1.00 | 1.00 | 0.12 | 0.13 |
| LSTM (default) | 1.00 | 0.12 | 0.13 | 0.13 |
| LSTM (f-bias=2) | 1.00 | 1.00 | 0.94 ± 0.06 | 0.13 |
| GRU (default) | 1.00 | 1.00 | 0.12 | 0.12 |
| GRU (z-bias=2) | 1.00 | 1.00 | 1.00 | 1.00 |

(Chance = 0.125. Values for T=50 and T=100 around 0.12-0.13 mean "complete failure".)

**What to say:**
- The RNN's memory breaks between 25 and 50 steps.
- With default initialisation the LSTM fails even **earlier** than the RNN (already at T=25) and the GRU fails at T=50, so gates alone do not help.
- With the gate bias set to 2, the GRU solves everything up to T=100 and the LSTM solves up to T=50.
- Loss curves at T=50: the default models stay flat at the chance loss `ln 8 ≈ 2.08` for all 1200 steps (they never even start learning). The LSTM (f-bias=2) drops within about 100 steps and settles near 0.2. The GRU (z-bias=2) stays at chance for about 80 steps, then drops to about 0 by step 300.

### Experiment 2: measuring the gradient directly (`exp2a_gradient_untrained.png`, `exp2b_gradient_trained.png`)
**What we did:** We unrolled each network step by step and measured `‖∂L/∂h_t‖`, the learning signal that reaches each timestep, relative to the last step. A line that falls steeply toward early timesteps = vanishing gradient. The y-axis is logarithmic, so a straight sloping line means exponential decay.

- **2a (untrained, T=100):** RNN and default LSTM/GRU decay by 18+ orders of magnitude (the RNN and LSTM lines hit the floor and drop off because the value is smaller than the smallest number float32 can hold). Setting the gate bias to 2 brings the value at t=1 up to about 10⁻³ for the LSTM and about 10⁻⁴ for the GRU.
- **Right panel of 2a, LSTM forget-bias sweep:** the gradient at t=1 improves steadily as the initial bias increases: underflow (bias 0) → about 10⁻⁹ (bias 1) → about 10⁻³ (bias 2) → about 10⁻¹ (bias 3).
- **2b (after training, T=50):** gradient at t=1 relative to t=T: RNN 1.5e-11, LSTM 1.3e-14, GRU 3.7e-10 (all essentially zero), LSTM f-bias=2 3.2e-2, **GRU z-bias=2 0.82** (nearly flat, i.e. almost no decay).

**What to say:** This is the direct evidence for the vanishing-gradient explanation. The models that failed in Experiment 1 are exactly the ones whose gradient vanishes, and the models that succeeded are the ones whose gradient survives. It also explains *why* they fail: if no learning signal reaches step 0, the network cannot learn to store the first symbol.

### Experiment 3: real text, IMDB sentiment (`exp3_real_dataset.png`)
**What we did:** Trained RNN, LSTM, GRU (default initialisation) on IMDB for 4 epochs. Pipeline: lowercase and split into words; keep the 10,000 most common words (others become `<unk>`); cut or pad every review to 200 tokens (padding on the **left**, so that real words end at the last step the classifier reads); 64-dimensional learned word embeddings; hidden size 128; batch size 64.

| Model | Params | Test accuracy |
|---|---|---|
| RNN | 665,090 | 64.1% |
| LSTM | 739,586 | 75.7% |
| GRU | 714,754 | 81.9% |

**What to say:** The gated models clearly beat the RNN on real language, and the GRU came out best while using fewer parameters than the LSTM. All three were still improving at epoch 4, so these are not final accuracies. The result comes from one seed. An earlier run of the same code gave 60.2 / 74.9 / 81.6%, so the RNN number varies by a few points between runs (Apple's GPU backend is not fully deterministic), but the ordering RNN < LSTM < GRU was the same.

### Experiment 4: looking inside the networks
**4a. Hidden-state PCA (`exp4a_hidden_pca.png`).** We took each review's final hidden state, projected it to 2D with PCA, and coloured points by true sentiment (red = positive, blue = negative). *PCA* finds the two directions along which the data varies most; mathematically: centre the data, compute the SVD, project onto the top two right singular vectors. RNN: red and blue are mixed, no structure. LSTM: points form an arc, with negative reviews on one end and positive on the other (some overlap). GRU: the two classes separate along the first axis (PC1) most clearly. This matches the accuracy ranking, so the hidden state of the better models really does encode sentiment.

**4b. Saturation (`exp4b_saturation.png`).** Histogram of all hidden values. The RNN's is U-shaped: 15.7% of its units sit at |h| > 0.9 (tanh extremes). The LSTM's is sharply peaked at 0 (0.1% saturated) and the GRU's is a broad bump (0.3%). Saturated tanh units have derivative near 0, which connects back to the vanishing-gradient bound in Section 2.2.

**4c. LSTM gates on real text (`exp4c_lstm_gates_text.png`).** Heatmaps of the three gate values (averaged over all 128 hidden units) for the last 25 words of one positive and one negative review. **Honest reading:** the gates mostly hover between 0.3 and 0.6, with no sharp word-by-word pattern. The clearest visible feature is that the input gate dips on `<unk>` (unknown word) tokens in both reviews, which means the network writes less into memory for words it does not recognise. Do not claim that the gates "detect sentiment words"; the figure does not show that. Averaging over units hides what individual units do.

**4d. Gates on the memory task (`exp4d_lstm_gates_memory.png`).** Mean forget-gate value over time: about **0.90** for the working LSTM (f-bias=2) and about **0.44** for the default LSTM that failed. A forget gate of 0.9 keeps `0.9` of the memory per step, so the first symbol survives; a gate of 0.44 destroys it quickly. This is the mechanism behind Experiment 1. The input gate averaged over units does **not** show a spike at t=0, so do not claim one.

## 5. Main conclusions (the story to tell)

1. **The vanilla RNN's memory collapses** somewhere between 25 and 50 steps, and its gradient to early timesteps is essentially zero (Exp. 1, 2b).
2. **Gates are not magic.** With default initialisation the LSTM and GRU fail as badly as, or worse than, the RNN, and have equally vanishing gradients (Exp. 1, 2).
3. **Gates work when they start open.** Setting the forget/update bias to 2 lets the GRU remember across 100 steps (gradient about 0.82 reaches the first step) and the LSTM across 50 steps. The forget gate sits near 0.9 in the working LSTM and near 0.44 in the failed one (Exp. 2, 4d).
4. **It matters on real text too:** the gated models beat the RNN on IMDB (about 76% and 82% vs 64%), and the RNN also has many saturated hidden units (Exp. 3, 4a, 4b).

## 7. Likely questions and good answers

**Q: What is the vanishing gradient problem, in one sentence?**
The learning signal from the loss shrinks exponentially as it is passed back through many timesteps, so early inputs barely influence the weight updates and the network cannot learn long-range dependencies.

**Q: Why did the default LSTM fail at T=25 when the plain RNN succeeded?**
Our measurements show the default LSTM's forget gate averages about 0.44, which destroys memory quickly, and the gradient to early steps is about 10⁻¹⁴. Our best explanation is that this starting point gives training almost no signal to find the solution within 1200 steps, while the RNN's recurrent weights can reach a per-step gain near 1 more easily. We did not test this hypothesis directly beyond the bias experiments, so present it as a likely explanation, not a proven fact. Longer training might also fix it; we did not test that.

**Q: Isn't setting the gate bias to 2 cheating?**
No. It is a standard initialisation trick from the literature, and it is the variable we are studying. We report the default-initialised models alongside them in every experiment so the comparison is transparent.

**Q: Why GRU > LSTM on IMDB? Is the GRU simply better?**
In our run it scored higher and uses 3/4 of the recurrent parameters, but this is a single seed and 4 epochs, so we do not claim the GRU is generally better. Published comparisons find them roughly similar; the difference here could come from training speed under our settings.

**Q: Why is IMDB accuracy only about 82%? Good models reach 90%+.**
We used only 10,000 training reviews, trained for just 4 epochs, truncated reviews to 200 words, learned embeddings from scratch (no pre-trained word vectors), and did not tune anything. The goal was to compare architectures under identical conditions, not to maximise accuracy.

**Q: Why not use Transformers or attention?**
They are outside the scope: the project is about understanding how recurrent memory works and why it fails. Attention/Transformers avoid the problem by connecting every step directly, and we mention them as future work.

**Q: Why is the padding on the left?**
The classifier reads only the last hidden state. With left padding, the real words come last, so the final state is not polluted by many steps of padding.

**Q: What does gradient clipping do and why use it?**
If the gradient norm exceeds 1 we rescale it to 1. It prevents exploding gradients, which can otherwise destabilise training of recurrent networks.

**Q: Why are some lines in the untrained gradient plot cut off at the bottom?**
At T=100 the gradient at early steps is smaller than the smallest number float32 can store (about 10⁻³⁸), so it becomes exactly 0 and cannot be drawn on a log axis. It means "extremely small", not exactly zero.

**Q: What is the gradient plot measuring for trained models?**
The gradient of the correct class's score with respect to the hidden state at each timestep, divided by the same quantity at the last step. A flat line near 1 means the early steps receive as much learning signal as the last; a steep drop means vanishing gradient.

**Q: Why did you not compare training time?**
On Apple's GPU backend the three layer types use very different internal kernels (our timings were 37 s for the RNN, 8 s for the LSTM, 88 s for the GRU), so those numbers say nothing about the architectures' real cost.

**Q: The numbers in your report differ slightly from someone's re-run. Why?**
GPU computation is not perfectly deterministic. The memory task results were the same on two machines except for one borderline case. The IMDB RNN accuracy varied by about 4 points between two runs. The ordering of the models was the same every time.

**Q: What is PCA and why use it?**
It finds the two directions in which the hidden-state vectors vary most, so we can draw a 128-dimensional space as a 2D picture and see whether positive and negative reviews end up in different regions.

## 8. Limitations (say them before someone else does)

- Only 2 seeds on the memory task; 1 seed and 4 epochs on IMDB. We have no error bars for IMDB.
- The LSTM with forget bias 2 at T=50 is a borderline case: one seed scored 0.25 on one machine and 0.885 on another. At T=100 it failed after 1200 steps, and longer training might help (untested).
- Only bias value 2 was used in full training runs; the sweep over 0, 1, 2, 3 is only for untrained gradients.
- No hyper-parameter tuning, and hidden sizes, learning rate and optimiser were fixed.
- The gate heatmaps average over all hidden units, so they do not show individual unit behaviour. The LSTM and GRU with the bias trick were not trained on IMDB (only the default models were).
- The memory task is synthetic: it isolates long-range memory but is not natural language.

**Things we must NOT claim:**
- "LSTM/GRU always beat the RNN." (Not true in our default-initialised memory results.)
- "The GRU is better than the LSTM." (One run only.)
- "The input gate spikes when the important symbol arrives." (Our figure does not show this.)
- "Gates detect sentiment words." (Our gate heatmap does not show this.)
- Any claim about training speed.

## 10. Glossary

- **Hidden state:** the vector a recurrent network uses as memory between steps.
- **Backpropagation through time (BPTT):** gradient computation that flows backward across all timesteps.
- **Vanishing / exploding gradient:** gradient becoming exponentially tiny / huge as it travels back through many steps.
- **Gate:** a sigmoid output between 0 and 1 that multiplies a signal to let more or less of it through.
- **Cell state:** the LSTM's separate long-term memory vector.
- **Bias initialisation:** the starting value of the bias term of a gate; a positive value makes the gate start open.
- **Saturation:** a tanh unit stuck near -1 or +1, where its derivative is about 0.
- **Gradient clipping:** rescaling the gradient when its norm exceeds a threshold.
- **Embedding:** a learned vector representing a word.
- **One-hot:** a vector with a single 1 and zeros elsewhere.
- **PCA:** projection onto the directions of greatest variance.
- **Epoch:** one pass through the whole training set.
- **Seed:** the number that fixes the random number generator for reproducibility.
- **Chance level:** accuracy of random guessing.
